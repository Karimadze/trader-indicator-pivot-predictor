# Широта рынка и обучение на 97 тикерах: что это дало

Продолжение исследования. Два изменения: выборка выросла с 7 тикеров до 97,
и добавлен рыночный контекст — сколько бумаг падает одновременно.

Данные: 97 тикеров NASDAQ из `vmc_ema_extended_data`, дневки, 663 623 бара,
**37 325 кандидатов** против прежних 1 572. Базовая частота PIVOT — 45,1 %.

---

## 1. Главная находка: дно надёжнее, когда падает весь рынок

Доля акций, у которых RSI ниже 30 в этот день:

| Акций с RSI < 30 | Кандидатов | Стали PIVOT | Цена через 5 дней |
|---|---:|---:|---:|
| 1–3 % (рынок спокоен) | 8 729 | 43,6 % | +0,87 % |
| 3–7 % | 9 682 | 43,8 % | +0,90 % |
| 7–15 % | 7 083 | 46,7 % | +0,72 % |
| 15–30 % | 3 225 | 49,6 % | +1,74 % |
| **более 30 % (широкая паника)** | 1 832 | **54,0 %** | **+1,71 %** |

Та же картина через долю акций выше своей MA20 — а это готовый тикер в
TradingView (`INDEX:NDTW` для Nasdaq-100):

| Акций выше MA20 | Кандидатов | Стали PIVOT | Через 5 дней |
|---|---:|---:|---:|
| менее 15 % (паника) | 6 367 | **48,5 %** | +1,50 % |
| 15–25 % | 5 923 | 47,1 % | +1,00 % |
| 25–40 % | 8 108 | 45,1 % | +0,87 % |
| 40–60 % | 9 364 | 43,7 % | +0,87 % |
| 60–80 % | 6 066 | 41,5 % | +0,66 % |
| более 80 % (всё спокойно) | 986 | **38,2 %** | +0,65 % |

Зависимость монотонная от края до края. Смысл простой: **когда акция валится
одна, а рынок спокоен — это её собственная проблема, и она обычно продолжается.
Когда валится всё сразу — это паника, а паника кончается быстро.**

## 2. Лучший фильтр стал ещё лучше

К фильтру капитуляции из прошлого отчёта добавлен рыночный контекст:

| Фильтр | n | Стали PIVOT | Train | Test | Через 5 дней |
|---|---:|---:|---:|---:|---:|
| капитуляция (падение 5д < −12 %, ATR > 1,2×, объём > 1,2×) | 1 722 | 53,1 % | 53,3 | 52,4 | +2,22 % |
| **+ акций выше MA20 менее 15 %** | 660 | **57,4 %** | 57,5 | **56,5** | +2,41 % |
| + акций выше MA20 менее 25 % | 840 | 56,9 % | 57,4 | 53,4 | +2,47 % |
| + доля новых минимумов RSI выше нормы на 1,5σ | 831 | 59,0 % | 59,8 | 55,5 | +3,00 % |
| **+ рынок СПОКОЕН (выше MA20 более 60 %)** | 219 | **51,6 %** | 50,6 | 55,3 | +2,36 % |

Обратите внимание на последнюю строку: та же капитуляция при спокойном рынке
даёт 51,6 % вместо 57,4 %. Разница в шесть процентных пунктов — это и есть
вклад широты.

## 3. Обучение на 97 тикерах вместо 7

Логистическая модель, 14 признаков, обучение на всём до 2021 года:

| Порог | Train | Test (все 97) | Test (ваши 7) |
|---|---:|---:|---:|
| без фильтра (база) | 45,1 % | 45,6 % | 47,3 % |
| score ≥ 0,50 | 52,3 % | 49,8 % | 51,2 % |
| **score ≥ 0,55** | 58,4 % | **59,1 %** | мало наблюдений |
| score ≥ 0,60 | 59,3 % | **60,0 %** | мало наблюдений |

Train 58,4 % против Test 59,1 % — на выборке в 24 раза больше прежней это уже
не совпадение, а устойчивая цифра.

На ваших семи тикерах при `score ≥ 0,50`: цена через 5 дней **+3,56 %,
положительных 67,1 %** против +1,92 % и 58,5 % без фильтра.

Внутри модели breadth-признаки добавляют около 1 п.п. точности — сами по себе
как отдельный фильтр они дают больше (+4–6 п.п.), потому что модель уже
частично улавливает то же самое через глубину падения.

## 4. Reversal Radar подтвердился на большой выборке

Те же 7 компонентов, но проверенные на 663 623 барах вместо 27 890:

| Совпало | На 7 тикерах (было) | На 97 тикерах (стало) | Train / Test |
|---|---:|---:|---|
| 2 из 7 | 50,1 % | 48,7 % | 49 / 47 |
| 3 из 7 | 58,0 % | 56,2 % | 57 / 53 |
| 4 из 7 | 66,3 % | 63,3 % | 64 / 59 |
| база | 7,8 % | 7,6 % | — |

Цифры просели на 2–3 п.п. — это нормально: маленькая выборка всегда чуть
оптимистичнее. Но структура полностью сохранилась.

С фильтром широты (акций выше MA20 менее 15 %) точность почти не меняется,
зато растёт доходность: при 4 из 7 через 5 дней **+1,6 % вместо +1,2 %**,
при 1 из 7 — **+1,5 % вместо +0,9 %**.

Это важный нюанс: **широта улучшает не столько попадание в дно, сколько то,
что происходит после него.** Отскок от общерыночной паники сильнее, чем
отскок от локальной просадки одной бумаги.

## 5. Что изменилось в индикаторе

`ReversalRadar.pine` обновлён до v2:

- новая группа настроек **«Широта рынка»**;
- символ по умолчанию `INDEX:NDTW` — процент акций Nasdaq-100 выше MA20;
  альтернативы: `INDEX:S5TW` (S&P 500), `INDEX:MMTW` (NYSE);
- два режима: **помечать** (сигнал выходит, но видно состояние рынка) или
  **блокировать** сигналы при спокойном рынке;
- метка сигнала получает звёздочку `*`, если рынок в панике — то есть если
  условие широты выполнено;
- в панели появилась строка `Широта рынка` с текущим значением и вердиктом
  `ПАНИКА` / `спокойно`;
- цифры в подсказках обновлены на проверенные по 97 тикерам.

Если `INDEX:NDTW` недоступен на вашем тарифе TradingView — просто снимите
галочку «Учитывать широту рынка», индикатор продолжит работать как v1.

## 6. Честный итог

| Что | Точность попадания в PIVOT |
|---|---:|
| Случайный кандидат | 45 % |
| Модель на 7 тикерах (первая версия) | 53–56 % |
| Reversal Radar 3 из 7 | 56 % |
| Модель на 97 тикерах | 59–60 % |
| Капитуляция + широкая паника | 57 % |
| Reversal Radar 4 из 7 | 63 % |

Потолок сдвинулся с 56 % до примерно 60–63 %, и теперь эти цифры стоят на
выборке в 24 раза больше. Дальше без данных другого типа — внутридневных
котировок, дат отчётностей, потоков опционов — расти будет очень трудно.

Расчёты: `research/breadth_study.py`.
