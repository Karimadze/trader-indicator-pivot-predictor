# Обзор конкурентов: другие проекты на GitHub по теме pivot/RSI-разворотов

Этой цели: понять, есть ли на GitHub индикаторы или скрипты, которые публикуют
измеренную точность прогноза разворотных точек — как эталон для сравнения с
цифрами в `REPORT_RU.md`, `PIVOT_ANATOMY_RU.md` и `BREADTH_REPORT_RU.md` этого
репозитория.

Изучено пять репозиториев: логика разобрана по исходному коду и README
(в двух случаях GitHub не отдал дерево файлов, разбор — по README и
доступным метаданным).

## Итог одной строкой

**Ни один из пяти репозиториев не публикует ни одной цифры точности** —
ни win-rate, ни precision, ни бэктест-статистики. Сравнивать точность
буквально не с чем: у конкурентов измерений просто нет.

## Что это значит для этого проекта

Единственное место в публичном пространстве этой темы, где вообще есть
измеренная, воспроизводимая точность прогноза разворотных точек с train/test
разбивкой по времени — это `research/REPORT_RU.md` и сопутствующие отчёты
в этом репозитории (45–63% по отдельным компонентам, до ~60% у составной
модели с широтой рынка). Это не повод для самоуспокоения — 45–63% далеко
от идеала — но это единственный вариант, где можно проверить, откуда цифра
взялась, и повторить измерение самостоятельно (`research/*.py`).
