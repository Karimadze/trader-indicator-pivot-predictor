# Анатомия PIVOT: что происходит перед разворотом

Данные: `MRVL COHR MU LITE GLW TER STX`, дневки 2010–2026, 27 890 баров.
Кандидат — свеча, где RSI обновил минимум за 45 баров: **1 572 штуки**.
Из них подтверждённым `PIVOT LOW` стали **45,7 %**.

Везде ниже сравниваются две группы: свечи, ставшие PIVOT, и свечи-кандидаты,
которые PIVOT не стали. Все признаки считаются **только по данным до закрытия
свечи**.

---

## 1. Плохая новость: подход к дну выглядит почти одинаково

Событийный профиль, средние по барам от −10 до +5:

| Бар | Движение PIVOT | Движение ложный | Объём PIVOT | Объём ложный | RSI PIVOT | RSI ложный |
|---:|---:|---:|---:|---:|---:|---:|
| −5 | −0,52 % | −0,41 % | 1,03 | 1,04 | 48,8 | 49,1 |
| −3 | −1,30 % | −1,01 % | 1,10 | 1,08 | 44,9 | 45,8 |
| −2 | −1,43 % | −1,31 % | 1,13 | 1,13 | 42,6 | 43,4 |
| −1 | −1,99 % | −1,70 % | 1,27 | 1,16 | 39,7 | 40,6 |
| **0** | **−3,39 %** | **−3,07 %** | **1,44** | **1,36** | **34,9** | **35,9** |
| +1 | **+2,48 %** | **−1,54 %** | 1,15 | 1,24 | 39,9 | 34,1 |
| +3 | +0,32 % | +0,22 % | 1,04 | 1,11 | 42,6 | 36,0 |

Смотрите на строку 0 и строку +1. **До самого разворота обе группы идут
практически ноздря в ноздрю**: −3,39 % против −3,07 %, объём 1,44× против 1,36×,
RSI 34,9 против 35,9. Разница появляется только на следующий день, когда всё
уже произошло.

Это и есть причина, по которой ни один индикатор не даёт 90 %. Форма подхода
к настоящему дну и к ложному дну почти неразличима.

## 2. Хорошая новость: глубина падения работает

Единственный признак с реальной силой — **насколько резко упали за 5 дней**.

| Падение за 5 дней | Кандидатов | Стали PIVOT | Train (<2021) | Test (≥2021) |
|---|---:|---:|---:|---:|
| хуже −25 % | 10 | **100 %** | 100 % | 100 % |
| от −25 % до −20 % | 37 | **75,7 %** | 75,0 % | 76,0 % |
| от −20 % до −15 % | 105 | 45,7 % | 42,2 % | 48,3 % |
| от −15 % до −12 % | 145 | 54,5 % | 53,9 % | 55,4 % |
| от −12 % до −9 % | 235 | 51,5 % | 50,0 % | 54,1 % |
| от −9 % до −6 % | 441 | 41,0 % | 41,0 % | 41,1 % |
| от −6 % до −3 % | 414 | 39,9 % | 41,2 % | 37,3 % |
| мельче −3 % | 184 | 46,2 % | 49,6 % | 39,3 % |

Логика простая и понятная: **резкий обвал — это капитуляция, она заканчивается
быстро. Медленное сползание — это распределение, оно продолжается.** Когда RSI
обновляет минимум чуть-чуть, на вялом падении −5 % за неделю, дна там обычно нет.

Ровно этим объясняется, почему в прошлом замере выиграли `CCI < −200` и пробой
нижней Боллинджера: оба ловят именно резкость движения, а не его факт.

Лучший по устойчивости — **падение 5д < −12 % И ATR > 1,2× И объём > 1,2×**:

это не подгонка. Частота — примерно 1 сигнал в год на тикер.

Через 5 дней после такого сигнала: **+3,74 % в среднем, 65,7 % положительных**
(случайный бар: +0,67 % и 54,8 %).

По годам держится: хуже всего 2022 (25 %, n=4), лучше всего 2020–2021 и 2026
(71–83 %). Малые n в отдельных годах — цифры по годам смотрите как ориентир.

## 4. Мифы: что НЕ работает

| Признак | n | Стали PIVOT | Отклонение от базы |
|---|---:|---:|---:|
| Длинная нижняя тень, «молот» (>0,4 диапазона) | 308 | 43,5 % | **−2,2 п.п.** |
| Закрытие в верхней трети свечи | 125 | 39,2 % | **−6,5 п.п.** |
| Бычье тело (close > open) | 179 | 44,1 % | −1,5 п.п. |
| Огромный дневной диапазон (> 2 ATR) | 104 | 45,2 % | −0,5 п.п. |
| Цена ниже EMA 200 | 809 | 45,9 % | +0,2 п.п. |
| Цена выше EMA 200 | 763 | 45,5 % | −0,2 п.п. |
| Гэп вниз более 2 % | 297 | 49,2 % | +3,5 п.п. |
| Всплеск объёма z > 2 | 234 | 50,9 % | +5,2 п.п. |
| Огромный красный день, хуже −7 % | 153 | 47,1 % | +1,4 п.п. |
| 5 падений подряд из 5 | 303 | 49,2 % | +3,5 п.п. |

Отдельно стоит выделить три вещи.

**Молот не работает.** Классический разворотный паттерн с длинной нижней тенью
даёт 43,5 % против базы 45,7 % — то есть немного ХУЖЕ, чем просто любой кандидат.

**Закрытие у максимума свечи не работает — оно вредит.** 39,2 % против 45,7 %.
Свеча, которая днём упала и выкупилась к закрытию, статистически чаще оказывается
не дном, а паузой в падении.

**Фильтр тренда по EMA 200 бесполезен для поиска pivot.** Разница между «выше» и
«ниже» — 0,4 процентных пункта. Он полезен для отбора того, что покупать, но не
для того, чтобы понять, где дно.

## 5. Цена ошибки: асимметрия сильная

| Группа | Через 1 день | Через 3 дня | Через 5 дней | Средняя просадка за 5 дней |
|---|---:|---:|---:|---:|
| Истинный PIVOT | +2,48 % | +3,50 % | +3,77 % | −2,13 % |
| **Ложный кандидат** | **−1,54 %** | **−1,73 %** | −0,90 % | **−5,94 %** |

Правильный сигнал даёт +3,77 % за 5 дней при просадке −2,1 %.
Ошибка стоит −0,9 % при просадке почти −6 %.

При точности 60 % математика выходит в плюс, но только со стопом. Без стопа
шесть процентов просадки на 40 % сделок съедают всё преимущество.

Разница понедельник/пятница — 5,7 п.п., на 1 500 наблюдениях это на грани

## 7. Готовый код для вставки в Pine

Фильтр капитуляции, который можно добавить к любому индикатору:

```pine
// Фильтр капитуляции: 60% попаданий в PIVOT против базы 46%
float atrNow  = ta.atr(14)
float atrRel  = atrNow / ta.sma(atrNow, 50)
float volRel  = volume / ta.sma(volume, 20)
float drop5   = (close / close[5] - 1) * 100

bool capitulation = drop5 < -12 and atrRel > 1.2 and volRel > 1.2
```

Строгий вариант, если нужна редкость и максимальная точность:

```pine
bool capitulationHard = drop5 < -20   // 75-100% попаданий, но 2-3 раза за 16 лет
```

## 8. Итог одной фразой

**Дно нельзя узнать по форме свечи. Его можно узнать по скорости падения.**

Всё, что описывает КАК выглядит свеча — молот, тень, закрытие, тело, гэп —
не работает. Работает только то, что описывает НАСКОЛЬКО БЫСТРО падали:
глубина за 5 дней, расширение ATR, всплеск объёма. И даже это даёт 60 %,
а не 90 %.
