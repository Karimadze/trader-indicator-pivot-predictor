# Reversal Radar Scanner для Bybit

Файл: `scanner/bybit_radar_scanner.py`. Только стандартная библиотека Python 3.8+,
ставить ничего не нужно.

## Что делает

Сам забирает с Bybit список инструментов и следит за всеми сразу:

| Что | Откуда | Сколько сейчас |
|---|---|---:|
| TradFi перпетуалы | `category=linear`, `symbolType=stock` | **164** |
| xStocks (токенизированные акции) | `category=spot`, `symbolType=xstocks` | **11** |

Список определяется автоматически по официальному полю `symbolType`, так что
новые инструменты Bybit подхватятся сами — правки в коде не нужны.

По каждому инструменту считаются те же семь компонентов, что в
`ReversalRadar.pine`, на **1ч и 4ч**, в обе стороны:

- **ЛОНГ** — дно: `CCI < −200`, пробой нижней Боллинджера, `RSI < 30`,
  Fisher из глубины, Ultimate Oscillator вверх через 30, TD9 buy setup,
  Connors RSI < 10.
- **ВЕРШИНА / фиксация** — зеркальные семь на максимуме.

## Главное: сигнал приходит ДО закрытия свечи

Каждый сигнал помечается статусом:

- `ФОРМИРУЕТСЯ` — условия выполнены прямо сейчас, на незакрытой свече. Это повод
  открыть график и посмотреть, а не готовая команда. До закрытия часа условие
  может исчезнуть.
- `ЗАКРЫТА` — свеча закрылась, сигнал зафиксирован. Вот это соответствует тому,
  что замерялось в исследовании.

Один и тот же сигнал не повторяется: состояние хранится в `radar_state.json`,
каждая комбинация «символ + таймфрейм + сторона + свеча + число совпадений +
статус» показывается один раз. Когда счётчик растёт с 3/7 до 4/7 — это уже новое
событие, и оно придёт снова.

## Фильтр волатильности

Вы просили бумаги вроде `USAR` — с большим дневным ходом. Мера — **ATR14 / цена**,
то есть насколько процентов инструмент проходит за средний день.

Как выглядит шкала на реальных данных Bybit:

| Инструмент | Средний дневной ход |
|---|---:|
| AAOI | 12,1% |
| AEHR, AXTI | 11,8% |
| NBIS | 9,6% |
| COHR | 9,0% |
| **USAR** | **6,2%** |
| MRVL | 6,5% |
| MU | 5,1% |
| TSLA | 3,1% |
| NVDA | 2,0% |
| AAPL | 1,5% |
| KO | 1,7% |

Медиана по всему списку — 4,5%.

```
python bybit_radar_scanner.py --volatile          ATR >= 4%  (около 59 бумаг)
python bybit_radar_scanner.py --min-atr 6         уровень USAR и выше
python bybit_radar_scanner.py --min-atr 9         только самые дикие
python bybit_radar_scanner.py --vol-top 20        20 самых волатильных
python bybit_radar_scanner.py --refresh-vol       пересчитать, не брать кеш
```

Волатильность считается по дневным свечам и **кешируется на 12 часов** в
`radar_volatility.json` — чтобы каждый проход не дёргал API лишний раз.

Значение с тильдой (`ATR 6.8%~`) означает, что у контракта меньше 25 дневных
свечей: часть TradFi-перпов Bybit запустил недавно, и оценка по ним
приблизительная. Совсем без данных остаются единицы — они пропускаются, и
сканер говорит сколько.

В журнале появилась колонка `ATR_%`, а сигналы сортируются сначала по числу
совпадений, потом по волатильности — самое интересное оказывается сверху.

## Запуск

```
cd trader-indicator-pivot-predictor/scanner
python bybit_radar_scanner.py
```

Полезные варианты:

```
python bybit_radar_scanner.py --once                 один проход и выход
python bybit_radar_scanner.py --min-conf 3           только 3/7 и выше
python bybit_radar_scanner.py --min-conf 4 --no-take только сильные лонги
python bybit_radar_scanner.py --tf 60                только часовой
python bybit_radar_scanner.py --category linear      только TradFi перпы
python bybit_radar_scanner.py --only NVDAUSDT MUUSDT конкретные тикеры
python bybit_radar_scanner.py --interval 60          проверять раз в минуту
```

Полный проход по всем 175 инструментам на двух таймфреймах занимает около
минуты. Пауза по умолчанию — 90 секунд.

## Что вы увидите

```
[17:49:02] NVDAUSDT   TradFi  4ч  ЛОНГ  4/7  ФОРМИРУЕТСЯ  цена 210.09  RSI 25
          свеча 24.08 15:00 МСК · сработали: CCI<-200, нижняя BB, RSI<30, ConnorsRSI<10
```

Зелёным — лонговые сигналы, красным — вершины. Плюс короткий звуковой сигнал,
когда в проходе появилось что-то новое.

Всё складывается в `radar_signals.csv` (разделитель `;`, кодировка с BOM —
Excel откроет корректно). По этому журналу через месяц можно будет честно
посчитать, сколько сигналов действительно оказались разворотами.


используется.

## Чего этот сканер не делает

- **Не учитывает широту рынка.** В Pine-версии есть фильтр по доле акций выше
  MA20; здесь его нет, потому что для Bybit-инструментов такого индекса нет.
- **Не проверен на 1ч и 4ч.** Все цифры точности (56% на 3/7, 63% на 4/7)
  получены на **дневных** графиках обычных акций. На младших таймфреймах
  сигналов будет заметно больше, а точность почти наверняка ниже — просто
  потому, что шума больше. Journal-файл как раз и нужен, чтобы это измерить.
- **Не даёт сигнал в шорт.** Верхние метки — это «вершина, подумай о фиксации».
  По замеру после них цена за 5 дней в среднем растёт, а не падает.

## Автозапуск при старте Windows (если захотите)

Создайте ярлык на `pythonw.exe` с аргументом — путём к скрипту — и положите его
в папку автозагрузки (`Win+R` → `shell:startup`). Либо запускайте руками, когда
садитесь за графики.
