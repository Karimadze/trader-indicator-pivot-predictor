# Trader Indicator Pivot Predictor

**🌐 Languages:** [Русский](#) (текущая) · [English](docs/README.en.md) · [中文](docs/README.zh.md) · [हिन्दी](docs/README.hi.md) · [Deutsch](docs/README.de.md) · [Español](docs/README.es.md)

Набор индикаторов Pine Script (TradingView) и отдельный Python-сканер для Bybit, которые пытаются **предсказывать разворотные точки RSI в реальном времени** — до подтверждения бара, а не постфактум, как это делает стандартный индикатор "RSI Div - Lib" (он рисует метки PIVOT только через 2 бара после факта).

Проект — результат честного, измеренного исследования, а не маркетинга. Здесь нет обещаний "90% точности". Ниже — реальные цифры, полученные на исторических данных с разбивкой train/test по времени (обучение до 2021 года, тест — после), чтобы избежать переобучения.

## ⚠️ Дисклеймер

Это не финансовый совет и не гарантия прибыли. Индикаторы и сканер — исследовательские инструменты, построенные на статистике прошлых цен. Торговля с использованием любых сигналов, включая эти, несёт риск потери капитала. Автор не является финансовым консультантом. Проверяйте всё самостоятельно перед принятием решений.

## Что внутри

- **`tradingview/`** — индикаторы Pine Script v6 для TradingView:
  - `RealtimePivotPredictor.pine` — скоринг вероятности разворота (0–100) на основе логистической регрессии с 7 признаками (RSI, растяжение от MA, положение относительно MA200, ATR, тело свечи, доходность за 3 бара). Не перерисовывается (`barstate.isconfirmed`, без заглядывания вперёд).
  - `ReversalRadar.pine` / `ReversalRadarV2.pine` — "Reversal Radar": confluence-индикатор из 7 компонентов (CCI, Bollinger Bands, RSI-пересечение, Fisher Transform, Ultimate Oscillator, TD Sequential 9, Connors RSI), симметрично считает сигналы снизу (LONG) и сверху (TAKE — не шорт, см. ниже почему), RSI-панель как у RSI Div-Lib, опциональный фильтр по ширине рынка.
  - `CausalPivotCandidate.pine`, `CyclicSmoothedRSI_MTF.pine`, `NasdaqVMCSeparatePane.pine`, `BybitStockPerpRegimeBreakout.pine` — вспомогательные и экспериментальные индикаторы из того же исследования.
  - README на русском для каждого индикатора — рядом в этой же папке.

- **`research/`** — весь путь к результатам: Python-скрипты, которыми всё было измерено (без TradingView, только stdlib/pandas), и отчёты в Markdown с цифрами:
  - `REPORT_RU.md`, `PIVOT_ANATOMY_RU.md`, `BREADTH_REPORT_RU.md`, `VMC_EMA_EXTENDED_REPORT_RU.md`, `BYBIT_2Y_COMBO_REPORT_RU.md` — отчёты по каждому этапу исследования.
  - Скрипты для воспроизведения: `realtime_pivot_predictor_study.py`, `reversal_radar_study.py`, `pivot_anatomy_study.py`, `breadth_study.py`, `divergence_study.py`, `bybit_two_year_combo_search.py` и другие.
  - CSV с данными для 7 стартовых тикеров (`divergence_data/`) и снапшот волатильности Bybit (`bybit_volatility_snapshot.csv`, `bybit_volatility_confirmed.csv`) — чтобы можно было пересчитать результаты без похода за новыми данными.

- **`scanner/`** — автономный Python-сканер (без зависимости от TradingView), который сканирует **весь живой список** TradFi-перпетуалов и xStocks на Bybit (1h/4h), включая ещё формирующийся (незакрытый) бар:
  - `bybit_radar_scanner.py` — основной скрипт, только стандартная библиотека Python 3.8+.
  - Фильтр волатильности (`--volatile`, `--min-atr`) для отбора тикеров с высокой дневной амплитудой.
  - `SCANNER_README_RU.md` — подробная документация с примерами команд.

## Честные цифры (кратко)

- Точность одиночных компонентов (CCI, BB, RSI-cross, Fisher, UO, TD9, Connors RSI) как предикторов разворота — обычно **45–63%**, никогда не приближается к 90%.
- Confluence из 4+ компонентов из 7 — точнее, чем любой компонент по отдельности, но реже срабатывает.
- Сигналы "TAKE" (верхние/vertex-сигналы) статистически надёжно ловят точки разворота RSI (до ~70% при conf≥4 + цена ниже EMA200), но **не являются шорт-сигналом**: средняя доходность за следующие 5 дней после такого сигнала всё ещё положительная. Поэтому они подписаны "TAKE" (сигнал к фиксации прибыли/выходу из лонга), а не "SHORT".
- Форма свечи (молот, длинная нижняя тень) сама по себе **не предсказывает** разворот — предсказывает скорость предшествующего падения и расширение ATR/объёма ("капитуляция": падение >12% за 5 дней + ATR ratio >1.2x + volume ratio >1.2x — самый устойчивый фильтр, ~60% точности, train/test почти идентичны).
- Широта рынка (доля акций с RSI<30 в корзине) монотонно улучшает надёжность сигналов по отдельным акциям — паника по всему рынку делает точечные развороты надёжнее.

Подробности с методологией и полными таблицами — в `research/*_REPORT_RU.md`.

## Быстрый старт

**Pine-индикаторы:** откройте нужный `.pine`-файл из `tradingview/`, скопируйте код в Pine Editor на TradingView → Add to chart.

**Сканер:**
```bash
cd scanner
python bybit_radar_scanner.py --volatile
```
Полный список флагов и примеров — в `scanner/SCANNER_README_RU.md`.

**Воспроизвести исследование:**
```bash
cd research
python realtime_pivot_predictor_study.py
```
